# HCW Template Project

Dokumentvorlage für Projekt- und Laborberichte der Hochschule Campus Wien.

Status: Grundstruktur angelegt; Inhalte und Projektbeispiele folgen.

## Neues Projekt aus der Vorlage erstellen

Dieses Repository ist als GitHub Template Repository eingerichtet. Für jeden
Projekt- oder Laborbericht wird daraus ein neues, unabhängiges Repository
erstellt:

1. Auf GitHub
   [FH-Campus-Wien/hcw-template-project](https://github.com/FH-Campus-Wien/hcw-template-project)
   öffnen.
2. **Use this template → Create a new repository** auswählen.
3. Eigentümer:in, Repository-Name und gewünschte Sichtbarkeit festlegen.
4. **Create repository** auswählen.
5. Das neu erstellte Repository klonen:

```shell
git clone https://github.com/ORGANISATION-ODER-BENUTZER/NEUES-REPOSITORY.git
cd NEUES-REPOSITORY
```

Wenn bereits ein persönliches Projekt-Repository bereitgestellt wurde, wird
direkt dessen Clone-URL verwendet. Das zentrale Template-Repository sollte
nicht direkt geklont werden, weil `origin` sonst weiterhin auf die Vorlage
zeigt. Für eine ausschließlich lokale Verwendung steht alternativ
**Code → Download ZIP** zur Verfügung.
